# [求解三次方根](https://www.acwing.com/problem/content/792/)
这道题目是浮点二分法
## 1️⃣ mid 只计算了一次（最严重的问题）

你在 while 外计算了 mid：

```double mid = (l + r + 1) >> 1;```

但在循环中 没有重新计算 mid。

所以：
```c++
while(r - l > 1e-8){
    if(mid * mid * mid >= x){
        l = mid;
    }else{
        r = mid - 1;
    }
}
```
mid 永远不变，l 或 r 可能不断变化但 mid 不更新，
循环条件始终成立 → 死循环 → 超时。

正确做法是 每次循环重新算 mid：

```double mid = (l + r) / 2;```

## 2️⃣ 位运算 >> 用错了

你写的是：

```(l + r + 1) >> 1```

>> 是 整数右移，但 l、r 之后会变成 double。

而且：

```(l + r + 1) >> 1```

是 整型二分写法。

浮点二分应该写：

```mid = (l + r) / 2;```

## 3️⃣ r = mid - 1 完全错误

浮点二分不能 -1：

```r = mid - 1;```

这会让区间直接跳很大，甚至破坏二分。

应该写：

```r = mid;```

## 4️⃣ printf 格式也错了

你输出：

```printf("%d",l);```

但 l 是 double。

应该：

```printf("%.6f", l);```

## 5️⃣ l、r 类型错了

你写：

```int l = -10000, r = 10000;```

但后面：

```c++
l = mid;
r = mid;
```

mid 是 double，赋值给 int 会 截断小数。

例如：
```c++
mid = 2.345
l = 2
```
这会导致：

r - l 永远很大

可能 无限循环 或结果错误。

必须改成：

```double l = -10000, r = 10000;```

## 🚀 二分模板总结

浮点二分标准写法：
```c++
 while(r - l > eps){
    mid = (l + r) / 2;
    if(check(mid))
        r = mid;
    else
        l = mid;
}
```

## ⭐ 再补充一个重要细节

很多题解写：
```c++
while(r - l > 1e-8)
```
但最后输出

```%.6f```

原因是：

1e-8 精度 > 1e-6 输出精度

这样可以 避免四舍五入误差。
