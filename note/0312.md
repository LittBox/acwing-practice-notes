# 归并排序（788 逆序对）

## 原题链接
- 🔗 [AcWing 790 - 逆序数对](https://www.acwing.com/problem/content/790/)

---

## ✅ AC 代码（C++）
```c++
#include <bits/stdc++.h>
using namespace std;
using LL = long long;

LL merge_sort(vector<int>& q, int l, int r) {
    if (l >= r) return 0;

    int mid = (l + r) >> 1;
    LL res = merge_sort(q, l, mid) + merge_sort(q, mid + 1, r);

    int i = l, j = mid + 1, k = 0;
    vector<int> temp(r - l + 1);

    while (i <= mid && j <= r) {
        if (q[i] <= q[j]) {
            temp[k++] = q[i++];
        } else {
            temp[k++] = q[j++];
            res += mid - i + 1;
        }
    }

    while (i <= mid) temp[k++] = q[i++];
    while (j <= r) temp[k++] = q[j++];

    for (i = 0; i < k; i++) {
        q[l + i] = temp[i];
    }

    return res;
}

int main() {
    int n;
    cin >> n;
    vector<int> q(n);
    for (int i = 0; i < n; i++) cin >> q[i];
    cout << merge_sort(q, 0, n - 1) << "\n";
    return 0;
}
```

## 📌 赛前必背要点（高频易错）
1. 归并排序需要修改同一数组，函数参数必须是引用：
   - `vector<int>& q`
2. 递归时不能漏传数组参数：
   - `merge_sort(q, l, mid)`
   - `merge_sort(q, mid + 1, r)`
3. 合并前必须先递归处理左右区间。
4. 统计逆序对核心语句：
   - `res += mid - i + 1;`
5. 回写原数组时必须写：
   - `q[l + i] = temp[i];`（不是 `q[i]`）
6. 临时数组长度为当前区间长度：
   - `r - l + 1`
7. 推荐使用局部变量（更稳）：
   - `LL res = ...`
