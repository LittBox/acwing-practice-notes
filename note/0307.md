# 选择第 k 小 & 归并排序（AcWing 788 / 789）

## 1) 快速选择（第 k 小）
- 链接： https://www.acwing.com/problem/content/788/

### ✅ AC 代码（C++）
```c++
#include <iostream>
#include <vector>
using namespace std;

vector<int> queue;

int quick_select(int l, int r, int k) {
    if (l == r) return queue[l];
    int x = queue[l];
    int i = l - 1, j = r + 1;
    while (i < j) {
        while (queue[++i] < x);
        while (queue[--j] > x);
        if (i < j) swap(queue[i], queue[j]);
    }

    int sl = j - l + 1;
    if (k <= sl) return quick_select(l, j, k);
    return quick_select(j + 1, r, k - sl);
}

int main() {
    int n, k;
    cin >> n >> k;
    queue.resize(n);  // 必须先分配空间，否则访问越界
    for (int i = 0; i < n; i++) cin >> queue[i];
    cout << quick_select(0, n - 1, k) << endl;
    return 0;
}
```

### 🧠 常见踩坑点
- `queue` 是全局 `vector<int>`，需要先 `resize(n)` 再用 `queue[i]`。
- `k` 是第 k 小元素（1-based）。

## 2) 归并排序（AcWing 789）
- 链接： https://www.acwing.com/problem/content/789/

### ✅ AC 代码（C++）
```c++
#include <iostream>
#include <vector>
using namespace std;

vector<int> queue;

void merge_sort(vector<int>& queue, int l, int r) {
    if (l >= r) return;

    int mid = (l + r) >> 1;
    merge_sort(queue, l, mid);
    merge_sort(queue, mid + 1, r);

    vector<int> temp;
    int i = l, j = mid + 1;
    while (i <= mid && j <= r) {
        if (queue[i] < queue[j]) {
            temp.push_back(queue[i++]);
        } else {
            temp.push_back(queue[j++]);
        }
    }

    while (i <= mid) temp.push_back(queue[i++]);
    while (j <= r) temp.push_back(queue[j++]);

    for (int k = 0; k < (int)temp.size(); k++) {
        queue[l + k] = temp[k];
    }
}

int main() {
    int n;
    cin >> n;
    queue.resize(n);
    for (int i = 0; i < n; i++) cin >> queue[i];
    merge_sort(queue, 0, n - 1);
    for (int i = 0; i < n; i++) cout << queue[i] << " ";
    return 0;
}
```

### 🧠 常见踩坑点
- `temp` 是临时数组，合并时要 `push_back`（或 `resize`）确保大小。
- 回写原数组要写 `queue[l + k]`，而不是 `queue[k]`。
