[802. 区间和](https://www.acwing.com/problem/content/804/)
你代码里的主要问题
1. #define N 300010; 多了分号

你写的是：
```c++
#define N 300010;
```
这样展开后会变成：
```c++
int a[300010;], s[300010;];
```
这是错的。

应该写成：
```c++
#define N 300010
```
或者更推荐：
```c++
const int N = 300010;
```
2. find 里 r 没声明

你写的是：
```c++
int l = 0; r = alls.size() - 1;
```
应改成：
```c++
int l = 0, r = alls.size() - 1;
```
3. mid 最好加括号

acwing上明确要带括号，不然无法ac

你写：
```c++
int mid = l + r >> 1;
```
虽然这里按运算优先级通常等价于 (l + r) >> 1，但建议明确写成：
```c++
int mid = (l + r) >> 1;
```
4. `item.first()` 写错

pair 的成员是变量，不是函数。

你写：
```c++
item.first()
```
应该写：
```c++
item.first
```
5. 插入时 c 没取出来

你写：
```c++
for(auto item: add){
    int x = find(item.first());
    a[x] += c;
}
```
这里 c 根本没定义。应该是：
```c++
for (auto item : add) {
    int x = find(item.first);
    int c = item.second;
    a[x] += c;
}
```
6. 查询时 item.right() 不存在

你写：
```c++
int l = item.first(), r = item.right();
```
pair 只有 first 和 second，没有 right()。

应该是：
```c++
int l = item.first, r = item.second;
```
7. 查询输出时忘了先离散化 `l` 和 `r`

你写：
```c++
cout << s[r] - s[l - 1] << endl;
```
这里的 l,r 还是原坐标，不能直接拿来当前缀和下标。

应该先：
```c++
l = find(l);
r = find(r);
cout << s[r] - s[l - 1] << endl;
```
8. 前缀和数组大小

再提醒一个核心点

这里前缀和数组的大小，不是按原坐标 -1e9 ~ 1e9 开，而是按 离散后的不同坐标个数 开。
这就是“化稀疏为稠密”。

原本坐标范围巨大，但真正出现的点只有最多 300000 个，所以只需要开 300010。

9. ac代码
```c++
// m 个操作,待离散的数 <= m,
//只将操作个数进收缩
#include<iostream>
#include<vector>
#include<algorithm>

using namespace std;

#define N 300010
typedef pair<int,int> PII;

int a[N],s[N];//离散化后的数组,前缀和数组
vector<int> alls;//待离散数据
vector<PII> query,add;

int find(int x){
    int l = 0, r = alls.size() - 1;
    while(l < r){
        int mid = (l + r) >> 1;
        if(alls[mid] >= x) r = mid;
        else l = mid + 1;
    }
    return r + 1;
}

int main(){
    int m,n;
    cin >> m >> n;
    for(int i = 0; i < m; i++){
        
        int x,c;
        cin >> x >> c;
        add.push_back({x,c});
        alls.push_back(x);
        
    }
    for(int i = 0; i < n; i++){
        int l,r;
        cin >> l >> r;
        query.push_back({l,r});
        alls.push_back(l);
        alls.push_back(r);
    }
    //去重
    sort(alls.begin(),alls.end());
    alls.erase(unique(alls.begin(),alls.end()),alls.end());
    //处理插入
    for(auto item: add){
        int x = find(item.first);
        a[x] += item.second;
    }
    //构建前缀和数组
    for(int i = 1; i <= alls.size(); i++){
        s[i] = s[i-1] + a[i];
    }
    //处理询问
    for(auto item: query){
        int l = find(item.first), r = find(item.second);
        cout << s[r] - s[l - 1] << endl;
    }
    
    
    return 0 ;
}
```
