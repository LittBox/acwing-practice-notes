# [AcWing 801. 二进制中1的个数](https://www.acwing.com/problem/content/803/)
核心模板 `int lowbit(int x)` 
<br>作用：返回整形数的二进制数表示的最后一个1
<br>例如:

```c++
int x = 8; // 8(10) -> 1000(2)
lowbit(x); // lowbit(x) ->   返回1000(2)   -> return 8,

int y = 13;   // 13(10) ->   1101(2)
lowbit(y);    // lowbit(y) -> 返回 1(2)   ->   return 1,
``` 

`lowbit()`的具体实现
```c++
int lowbit(int x){
    return x & -x;   // -x =>  ~x + 1
                    // x & -x => x & (~ x + 1)
}
```

✅提交代码
```c++
#include<iostream>

using namespace std;

int lowbit(int x ){
    return x & -x;
}

int main(){
    int n;
    cin >> n;
    while(n--){
        int x;
        cin >> x;
        int res = 0;
        while(x) {
            x -= lowbit(x);
            res++;
        }
        cout << res << " ";
    }
}
```
