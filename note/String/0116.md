# 回文字符串（AcWing 5999）
- 链接： https://www.acwing.com/problem/content/description/5999/

## 🧠 核心掌握要点
- 字符串反转：
  - 使用库函数：`reverse(str.begin(), str.end());`（头文件 `<algorithm>`）
  - 或手动实现：
    ```c++
    void reverse(string &s) {
        int n = s.length();
        for (int i = 0; i < n / 2; i++) {
            swap(s[i], s[n - 1 - i]);
        }
    }
    ```
- 截取子串：
  - `str.substr(pos)` 或 `str.substr(pos, n)`
- 字符串比较：
  - `==` 或 `str1.compare(str2)`

## 📌 解题核心思路
题目要求：只能在字符串「开头」插入合法字符（`l/q/b`），不能修改其他位置，判断能否最终组成回文。

核心做法：把字符串拆成三部分——左合法段 A、核心段 B、右合法段 C，判断 B 是否回文并验证 A 和 C 的对称关系。

### ✅ 代码（C++）
```c++
#include <iostream>
#include <algorithm>
#include <string>
using namespace std;

int main() {
    int T;
    cin >> T;
    while (T--) {
        string s;
        cin >> s;

        int l, r;
        for (r = s.size() - 1; r >= 0 && (s[r] == 'l' || s[r] == 'q' || s[r] == 'b'); r--);

        if (r <= 0) {
            cout << "Yes" << endl;
            continue;
        }

        for (l = 0; l < r && (s[l] == 'l' || s[l] == 'q' || s[l] == 'b'); l++);
        string tmp = s.substr(l, r - l + 1);
        string rev = tmp;
        reverse(rev.begin(), rev.end());
        if (rev != tmp) {
            cout << "No" << endl;
            continue;
        }

        while (l >= 0 && r < (int)s.size() && s[l] == s[r]) {
            l--;
            r++;
        }
        cout << (l == -1 ? "Yes" : "No") << endl;
    }
    return 0;
}
```
