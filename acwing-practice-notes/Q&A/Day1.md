> C++ 中 为什么 scanf 比 cin 的读取速度快：
1. 同步机制
C++ 的 cin 和 cout 为了能与 C 的 scanf/printf 混用，默认会与 C 的 stdio 缓冲区保持同步。这意味着每次输入输出操作都需要进行同步，增加了额外的函数调用和锁开销。

2. 缓冲区处理
cin 是类型安全的，它会根据变量类型解析输入，这个过程会进行一些额外的检查（如跳过空白符、类型匹配等）。而 scanf 通过格式字符串直接指定类型，解析过程更底层，因此更快。

3. 流式设计的开销
C++ 的 IO 流使用了运算符重载和继承等面向对象特性，虽然方便，但相比 C 的纯函数调用，多了虚函数调用等开销。
