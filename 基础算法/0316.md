# [799. 最长连续不重复子序列](https://www.acwing.com/problem/content/801/)

这段代码有几处明显问题：
## 1.
```c++
#define 100010 N //写反了
```
应该是：
```c++
#define N 100010
```
## 2.
数组定义写反了
你写的是：
```c++
int[N] a;
int[N] b;
```
正确写法是：
```c++
int a[N];
int b[N];
```
## 3.
滑动窗口收缩时写错了
这里：
```c++
while(b[a[i]] > 1){
    b[a[i]] --;
    j++;
}
```
应该减少的是左端点对应元素的出现次数，而不是一直减 a[i]。正确写法：
```c++
while(b[a[i]] > 1){
    b[a[j]]--;
    j++;
}
```
## 4.
最后没有输出结果
你算出了 res，但没有 cout。

## AC

```c++
#include<iostream>
#define N  100010 

using namespace std;

int a[N];
int b[N];
int main(){
    int n;
    cin >> n;
    for(int i = 0; i < n; i++) cin >> a[i];
    int res = 0;
    for(int i = 0, j = 0; i < n; i++){
        b[a[i]]++;
        while(b[a[i]] > 1){
            b[a[j]] --; //这里是j不是i
            j++;  //这个相当于记录左边届
        }
        res = max(res,i - j + 1);
    }
    cout << res;
    return 0;
}
```

# [800. 数组元素的目标和](https://www.acwing.com/problem/content/802/)

## AC

```c++
#include<iostream>
#define N 100010

using namespace std;

int a[N],b[N];

int main(){
    int m,n,c;
    scanf("%d%d%d",&m,&n,&c);
    for(int i = 0; i < m; i++) scanf("%d",&a[i]);
    for(int i = 0; i < n; i++) scanf("%d",&b[i]);
    
    for(int i = 0,j = n - 1; i < m; i++){. //j = n-1 容易写成 n
        while(a[i] + b[j] > c) j--;
        if(a[i] + b[j] == c){
            printf("%d %d", i,j);
            break;
        }
    }
    return 0;
}
```

# [2816. 判断子序列](https://www.acwing.com/problem/content/2818/)

```c++
#include<iostream>
#define N 100010

using namespace std;

int a[N],b[N];

int main(){
    int m,n;
    cin >> m >> n;
    for(int i = 0; i < m; i++) scanf("%d",&a[i]);
    for(int i = 0; i < n; i++) scanf("%d",&b[i]);
    
    int i = 0,j = 0; 
    while(i < m && j < n){   //这里容易错写成 "||"
        if(a[i] == b[j]) i++;
        j++;
    }
    if(i == m) puts("Yes");
    else puts("No");
    
}
```
